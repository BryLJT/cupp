Wireframes, v2 — the social cut

Direction locked 17 Jul with Bryan's sign-off: the feed goes social (For You · Following · Mine), the search tab is a discovery page filterable by origin, roaster, and brew method, ratings are four 1–5 tasting characteristics plus overall stars, and logs are public by default with a per-log Private toggle. Brew templates: saved recipes that prefill the brew section, plus custom method names. Roastery palette unchanged. Decision log at the bottom.

v2.1 · 17 Jul 2026 · supersedes v1 · social sign-off recorded · rating model per SCA cupping attributes

The flow

Five-slot bottom bar, Instagram anatomy: feed, search, camera (raised — still the app's hero action), create, profile. Scan and manual create both end at the same review form.

Sign in → Feed (for you · following · mine) → ◉ Scan bag → reading → prefilled form ＋ Create → blank form ⌕ Search → discovery (filter by origin/roaster) → Review & save (public/private) → Feed · Profile

Screens

Caramel still marks one primary action per screen. Post anatomy is IG's — attribution header, photo, action row — but the action row's second life is coffee data: stars, brew chips, characteristics.

Cost, build order, and the decision log

✓ Social is un-cut — signed off 17 Jul (§13 satisfied)

The 16 Jul cut list excluded all social features; the team reversed that on 17 Jul with Bryan's agreement. This page is the record. Going social is not one feature — it's a schema change plus four:

PieceWhat it needs
Public/private logsvisibility column + RLS policy allowing public reads. Foundation for everything below.
Followsfollows table, follow/unfollow UI, “Following” feed query.
Likeslikes table, toggle + counts. Cheap once visibility exists.
Commentscomments table, thread UI, input handling. The most work — and committed for launch, per the 17 Jul decision.
Brew templatesbrew_templates table (name + method + dose/ratio/grind/temp per user); custom method names ride along free.
DiscoverySearch + filter queries over public logs. No new tables.

Build order, protecting the 25 Jul happy-path deadline: scan flow stays lane one and untouchable. Social lane builds visibility → discovery → follows → likes → comments → templates. Comments are committed, not optional — which makes the social lane a full-person job; if it slips, flag it in the group chat early rather than quietly cutting.

  1. Social un-cut — Bryan signed off.Feed, follows, likes, comments all in; §9 superseded for these, §13 satisfied.
  2. New logs default to Public.The Private toggle stays on every log form.
  3. Follows are one-way, IG-style.No request/accept flow.
  4. Likes and comments both ship at launch.
  5. Characteristics locked: Strength · Acidity · Sweetness · Bitterness + Overall stars.
  6. Discovery filters: origin, roaster, brew method.Custom methods surface as filter chips automatically.
  7. Home hosts For You | Following | Mine; Search stays pure discovery.For You = all public logs, so a new user's feed is never empty.
  8. Brew templates: saved recipes + custom method names.A template prefills the brew section. The full custom form-field builder stays cut per §9.
Decisions locked — next: theme file (constants/theme.ts), tab layout (app/(tabs)/), and the schema draft including social + template tables. Screens 04–06 remain the demo spine and get built first.
